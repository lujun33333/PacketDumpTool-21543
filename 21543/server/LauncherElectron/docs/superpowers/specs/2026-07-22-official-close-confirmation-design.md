# 官服式关闭确认设计

## 目标

在登录页与登录后主页共用同一个官服式关闭确认弹窗，并统一标题栏关闭、`Alt+F4`、托盘恢复和彻底退出行为。

## 交互

- 点击标题栏关闭或按 `Alt+F4` 时，若未记住选择，显示共享弹窗。
- 弹窗沿用官服结构：标题“提示”、正文“您点击了【关闭】，您希望：”、横排单选项、黄色“确定”按钮和“不再提醒”。
- 默认选择“最小化系统托盘”；关闭弹窗或按 `Escape` 只取消本次关闭。
- 只有点击“确定”且勾选“不再提醒”后才保存选择；未勾选则下次继续询问。
- “最小化系统托盘”隐藏窗口并保留预加载会话；“退出启动器”走现有完整清理与退出流程。
- 托盘菜单提供“打开启动器”“恢复关闭提示”“退出启动器”。恢复操作清除已记住选择并重新显示窗口。
- 开始游戏后的自动隐藏继续走独立的 `hideForGameLoading` 链路，不触发关闭确认。

## 进程边界

- renderer：渲染弹窗、管理焦点、读取和写入关闭偏好。
- preload：只暴露具名的关闭请求、关闭动作和两个只读事件订阅。
- main：拦截原生关闭、验证 IPC sender、执行托盘隐藏或真实退出、处理托盘菜单。

## 数据

关闭偏好存放在 renderer 的 `localStorage`，结构仅包含 `version`、`skipPrompt` 和 `action`。损坏或未知值回退为“每次询问 + 默认最小化到托盘”。

## 验收

1. 登录页和主页点击同一个关闭按钮均显示相同弹窗。
2. `Alt+F4` 显示同一个弹窗。
3. 默认选中“最小化系统托盘”。
4. 未确认、未勾选或按 `Escape` 都不会保存“不再提醒”。
5. 记住最小化/退出后，下次关闭直接执行对应动作。
6. 托盘恢复提示后，下次关闭重新显示弹窗。
7. 开始游戏隐藏行为不进入关闭确认链路。
